【第4回】お声がけされやすい！お取引ツイートの出し方

前回の記事では「交換・譲渡・買取」の違いをご紹介しました♪ 今回は、実際にお取引の募集ツイートを出す方法を、テンプレートつきで解説します！

この記事のテンプレートをそのままコピペして使えば、情報が過不足なく伝わる募集ツイートが作れます👌🏻

1. ツイートに記載すべき内容

募集ツイートには、以下の情報を入れるのが基本です。

項目書く内容例
お取引の種類交換 / 譲渡/ 買取【交換】
ジャンル名作品名・シリーズ名○○（作品名）
グッズ名グッズのシリーズ名○○コレクションなど
グッズの種類アイテムのカテゴリトレカ、缶バッジ、アクスタなど
譲（提供）自分が出せるものキャラ名＋個数
求（希望）自分が欲しいものキャラ名、または定価＋送料
条件求める個数や優先事項など「△△は5点求めています」など
発送方法郵送 or 手渡し郵送ではなく、駅やイベント会場などで直接会って物品を受け渡すこと。郵送

2. 交換ツイートの例

【交換】 ジャンル名　グッズ名　グッズの種類

譲 : ⚪︎⚪︎2　◻︎◻︎3

求 : △△

✔︎郵送

✔︎△△は5点求めています

お気軽にお声がけください
ポイント：
  • 「譲」に自分が手放せるキャラ名と個数を、「求」に欲しいキャラ名を書きます
  • 複数キャラを持っている場合は、まとめて記載してOKです
  • 条件（求めている個数など）があれば ✔︎ で箇条書きにすると見やすいです
  • IDが写ったグッズの写真を添付してください

3. 譲渡ツイートの例

【譲渡】 ジャンル名　グッズ名　グッズの種類

譲 : ⚪︎⚪︎2　◻︎◻︎3

求 : 定価+送料

✔︎郵送

✔︎PayPayもしくは銀行振込

お気軽にお声がけください
ポイント：
  • 「求」には金額（定価＋送料）を記載します
  • お金の受け取り方法（PayPay・銀行振込など）は必ず明記しておきましょう
  • 金額は定価以上の価格を設定すると「高額転売」と見なされることがあるので注意です
  • IDが写ったグッズの写真を添付してください

4. 買取ツイートの例

【買取】 ジャンル名　グッズ名　グッズの種類

譲 : 定価+送料

求 : △△

✔︎郵送

✔︎〜10点求めています

✔︎PayPayもしくは銀行振込

お気軽にお声がけください
ポイント：
  • 買取の場合は「譲」に自分が支払う金額、「求」に欲しいキャラ名を書きます（譲渡と逆になるので注意！）
  • 何点まで求めているかを書いておくと、複数持っている相手が声をかけやすくなります
  • IDが写ったグッズの写真を添付してください

5. 「比率違い」ってなに？

お取引でよく見かける「比率違い」について解説します。

比率違いとは、交換するグッズの数が1対1ではない交換のことです。

【例】
  • 自分のグッズ2個 ↔ 相手のグッズ1個（2:1の交換）
  • 自分のグッズ1個 ↔ 相手のグッズ3個（1:3の交換）
なぜ比率違いが起きるの？
  • キャラクターによって需要に差があるため
  • 相手が「どうしても欲しいキャラ」の場合、複数個出してでも交換したいと思うことがある
比率違いを提案するときのマナー：
  • 相手から提示されていない限り、自分から「自分2:相手1でお願いします」とは言わないのがマナーです
  • 募集ツイートに「比率違い可」と書いてある場合のみ、比率違いの提案が可能です
  • 自分のツイートに書く場合は「比率違いでのお声がけもお待ちしております」などと添えましょう

6. ツイートを出すときの注意点

  • 画像を添付しよう：グッズの実物写真（ID付き）を添付すると、信頼度と反応率がアップします
  • 「譲」と「求」を間違えない：逆に書いてしまうと、全く違う意味になってしまいます。投稿前に必ず確認しましょう
